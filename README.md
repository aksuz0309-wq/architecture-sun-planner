# Facade Light

場所・建物の向き・日付から、外観撮影に向く時間帯を割り出す静的Webアプリ（サーバー不要）。

## 機能
- 現在地・地図タップで場所を指定（住所検索は、入力した住所を外部へ送らないよう廃止）
- 地図上で建物を移動・回転・サイズ変更し、面ごとの順光/斜光/逆光、ゴールデン/ブルーアワーを算出
- MET Norway（商用利用可・無料）の雲量予報を加味（約9日先まで。過去日は不可。最初の約60時間は1時間ごと、その先は6時間ごと）
- 太陽の高さ：横から見た断面図（建物の高さ・影の長さ・高度角）と1日の高度グラフ
- ベスト日探し（30日〜1年）
- 状態はURLのハッシュに保存（共有可）。PWA対応（ホーム画面に追加可）

## 開発
```bash
python3 -m http.server 8777    # http://localhost:8777/
node tests/sun.test.js         # 太陽計算のテスト
```

## 構成
- `js/sun.js` 太陽位置・光の分類（ブラウザ/Node両用）
- `js/weather.js` 雲量の取得（MET Norway）
- `js/app.js` 画面と地図
- `mock/` 初期のUIモック（本体からは使わない）

## 既知の制限
- タイムゾーンは、現在地(GPS)なら端末の設定、地図で指定した場所は経度からの推定（日本は+9）。夏時間のある地域を遠隔で指定すると、1時間ずれることがあります
- 航空写真は日本国内のみ（国土地理院）
- 周囲の建物・地形による影は考慮しません

## プライバシー
- 検索エンジンには載せない設定（noindex）。
- 天気APIへ送る位置は小数2桁（約1km）に丸める（規約の上限は4桁）。
- 外部に正確な位置が届くのは、地図タイル（表示範囲）のみ。
- アプリのURLには場所・設定が入る（`#...`）。URLを共有すると場所も伝わる。
