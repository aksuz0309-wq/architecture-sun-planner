# 外観撮影 光読みプランナー

場所・建物の向き・日付から、外観撮影に向く時間帯を割り出す静的Webアプリ（サーバー不要）。

## 機能
- 現在地・住所検索（国土地理院）・地図タップで場所を指定
- 地図上で建物を移動・回転・サイズ変更し、面ごとの順光/斜光/逆光、ゴールデン/ブルーアワーを算出
- Open-Meteo の雲量予報を加味（約16日先まで、過去日は観測値）
- 太陽の高さ：横から見た断面図（建物の高さ・影の長さ・高度角）と1日の高度グラフ
- ベスト日探し（30日〜1年）
- 状態はURLのハッシュに保存（共有可）。PWA対応（ホーム画面に追加可）

## 開発
```bash
python3 -m http.server 8777    # http://localhost:8777/
node tests/sun.test.js         # 太陽計算のテスト
```

## 構成
- `js/sun.js` 太陽位置・光の分類（ブラウザ/Node両用）
- `js/weather.js` 雲量の取得
- `js/app.js` 画面と地図
- `mock/` 初期のUIモック（本体からは使わない）

## 既知の制限
- 夏時間のある地域では、天気取得に失敗した日の時刻が1時間ずれることがあります
- 航空写真は日本国内のみ（国土地理院）、住所検索も日本国内のみ
- 周囲の建物・地形による影は考慮しません
